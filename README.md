# 🧠 NLP-Based Resume Parser

A Natural Language Processing (NLP) project designed to automatically extract useful information such as name, email, phone number, education, skills, and more from resumes in plain text or PDF format.

---

## 🚀 Features

- 📧 Email and 📞 Phone number extraction using Regex
- 🎓 Education section extraction with heuristics
- 💼 Skill matching using a predefined skill set
- 🔍 Named Entity Recognition (NER) using spaCy
- 📝 Resume parsing from plain text
- 🔧 Extendable for other fields (e.g., certifications, projects)

---

## 🛠 Tech Stack

- *Python*
- *spaCy* (for Named Entity Recognition)
- *Regular Expressions (re)* (for pattern-based extractions)
- *Jupyter Notebook* (for interactive development)
